# CLAUDE.md — guide for AI coding tools

Acme Group Business Licenses Monitoring System (BLMS): tracks statutory licenses/permits per factory unit,
review workflow, expiry notifications. Node 22.13+, TypeScript everywhere.

## Architecture
* **Frontend** `src/` — React 19 + Tailwind 4 + Vite. `src/App.tsx` is a session gate (`App`) around `AppInner`,
  which holds all state (`AppStateData`) and syncs changes to the server (debounced `pushChanges()` in `src/utils/storage.ts`, one route per section, revision-checked).
  Tabs live in `src/components/*Tab.tsx`. Types in `src/types.ts`. API client in `src/utils/storage.ts`.
* **Backend** `server/` — Express + built-in `node:sqlite` (Node 22.13+, no native modules).
  * `index.ts` routes/middleware; `auth.ts` scrypt hashing, signed cookie session, CSRF header guard, login throttle;
  * `db.ts` connection, migrate (`database/schema.sql`), seed (`database/seed.sql`);
  * `state.ts` record-level authorization (`saveLicenses`, `saveUsers`, `saveSettings`, ...) with revision checks.
  * Route table with per-route `requireAuth`/`requireRole`: header of `server/index.ts` and `docs/API.md`.
* **Database** `database/schema.sql` (tables: users, licenses, settings, audit_log, activity, notification_log, meta),
  `database/seed.sql` is generated by `scripts/generate-seed.ts` from `src/constants/*` — don't edit by hand.

## Conventions
* Never put credentials in code or seed data. Passwords are plain text only in transit (`UserAccount.newPassword`),
  hashed server-side, never returned.
* New persisted setting → add its key to `SETTING_KEYS` in `server/state.ts` (admin-only by default).
* New mutating behaviour → add a route with `requireAuth` + `requireRole` (update the table in `server/index.ts` and `docs/API.md`) and enforce on the server; the UI is not a security boundary.
* Logs (audit/activity/notification) are append-only on the server.

## Commands
`npm run dev` (API :3000 + Vite :5173) · `npm run build` (web → `dist/`, server → `dist-server/index.cjs`) ·
`npm start` · `npm run lint` (tsc) · `npm test` (node:test, spawns the server on a temp DB) · `npm run seed:generate`.
Required env: `SESSION_SECRET` (prod), `ADMIN_PASSWORD` (first start). See `.env.example`, `HowToSetup.md`.
